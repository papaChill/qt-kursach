Проект реализован для быстрой работы с 2 статичными массивами - справочниками. 
В первом справочнике с тренерами, структурой ускоряющей работу (поиск вставку удаление) является хеш-таблица с методом разрешения коллизий через открытую адресацию с квадратичным пробированием, используется 3 статуса "empty" "occupied" "deleted".
Структурой второго справочника с тренировкми является авл-дерево с динамическими списками. внутри узла есть ключ и динамический список 
Если удаляется запись с тренером в первом справочнике то удаляется и все тренировки во втором.
